# UX round 3: the audit fixes

Source: the `auditing-gym-tracker-ux` audit, run 2026-10-06 (41 verified findings; the report sits in the git-ignored `.superpowers/ux-audit/REPORT.md`). Each batch is shipped on its own: build it test-first, push, check the deploy, then run the long suites.

## Owner decisions (2026-10-06)

- **After a lift, show what's left.** Not a single "Next" button: the owner goes to whichever machine is free.
- **The session summary leads with the main lifts' weights**, compared with last time, **plus the sets each muscle group got**.
- **One gym.** The gym batch (Today chip, flagging lifts the gym can't do, gym shown on Today) is parked.
- **Energy stays a log entry.** No low-energy offer.
- **The weekly goal stays at 2.** Fix only the Monday "everything under" false alarm. Don't infer days from the log.
- **Typo guard at 2× the best working weight.**
- **Notes shorthand: RDL only.** No kg.
- **Rename and merge lifts are in.** Moving to a new phone is parked.

## Batch 2: closing a session

- **S7-01:** a persistent PR tag on the set row and on the folded line, worked out from the stored entries.
- **S7-03:** a summary card below the exercise cards with each lift's top set against last time, PRs, and sets per muscle group today.

## Batch 3: plan rows and undo

- **S1-01:** plan rows show the target ("2 × 8+ @ 140 lb").
- **S3-01:** delete a set straight away, with a "Set deleted · Undo" bar for 8 s instead of `confirm()`.
- **M2-02/W1-03:** Rebuild keeps the previous program for undo.

## Batch 4: notes and review screens

- **D2-01:** a line that is only a weekday ("Sunday", "yesterday") is read as a date.
- **D2-02:** "135 lbs x 10" and "135 for 8" parse.
- **D2-03:** "RDL" maps to Romanian Deadlift.
- **M1-02:** `weekPace` uses `dow/7`, so Monday's floor is 0.
- **W2-01:** on Stats, muscles under target sort first.
- **D3-02:** Lifts rows show the last top set.
- **Y2-01:** History gets month headings.
- **M2-03:** explain the priority scale.

## Batch 5: rename and merge a lift (Y4-01)

From the lift screen: rename it, or merge it into another lift. Every set, program slot, plan swap, per-lift setting and name mapping moves over. Sync-safe: the old rows are tombstoned and new rows written.

## Constraints

- The commit button's accessible name keeps starting with "Add set", because the e2e specs locate it by that name.
- Re-measure at 375×812 after each batch with the audit harness.
